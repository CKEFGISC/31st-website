# 建北電資 31st 社網

[ckefgisc.org](https://ckefgisc.org)

以 [Astro](https://astro.build) + [React](https://react.dev) + [Tailwind CSS](https://tailwindcss.com) 打造的靜態網站。

```bash
bun install     # 安裝套件
bun run dev     # 開發伺服器 http://localhost:4321
bun run build   # 產生靜態檔案到 dist/
bun run deploy  # 建置並推上 GitHub Pages
```

改內容、加幹部、加課程請看 [docs/README.md](docs/README.md)。
